Atue como um especialista em desenvolvimento front-end e design de landing pages modernas.

Seu objetivo é criar uma landing page profissional, elegante e responsiva para um portfólio de projetos em Power BI.

## ⚙️ Requisitos técnicos

* Gere um único arquivo completo em HTML5
* Inclua CSS dentro do próprio arquivo (tag <style>)
* NÃO use frameworks externos (sem Bootstrap, Tailwind, etc.)
* Código limpo, organizado e comentado
* Layout totalmente responsivo (mobile-first)
* Compatível com celular, tablet, desktop e TV

## 🎨 Design e UX

* Design moderno, minimalista e profissional
* Use uma paleta de cores neutra e agradável para análise de projetos (ex: tons de azul, cinza e branco)
* Tipografia limpa e legível
* Espaçamento bem distribuído (whitespace)
* Animações suaves (hover, transições)
* Destaque visual para os projetos

## 🧠 Estrutura da página

Crie as seguintes seções:

1. Hero (apresentação do profissional)
2. Sobre
3. Portfólio de Projetos (grid responsivo)
4. Contato
5. Footer

## 📊 Projetos (IMPORTANTE)

Para cada imagem de projeto:

* Crie:

  * Título
  * Subtítulo
  * Tags
  * Descrição do projeto (curta e profissional)
  * Hashtags relevantes

* As imagens devem:

  * Ter efeito de desfoque (blur) para ocultar dados sensíveis
  * Ter overlay ao passar o mouse com informações do projeto

## 🖼️ Imagens

* Usarei imagens reais depois, então use placeholders
* Inclua estrutura pronta para substituição fácil
* Avatar deve ser circular e destacado
